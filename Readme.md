#  Dados e Automações

Este é o repositório central para estudos e implementações de Engenharia de Dados, Automações e Segurança (Purple Team).

##  Estrutura do Repositório

- **semana-07/**: Projetos de Engenharia de Dados e IA (SOC Investigator, Chatbot, PDF Analyzer).
- **docs/**: Documentação técnica do ecossistema.

##  Tecnologias Utilizadas

- Python (Pandas, Streamlit)
- Inteligência Artificial (OpenAI GPT-4o-mini)
- Automação de Workflows (n8n)

##  Segurança e Governança

Todas as chaves de API e segredos são gerenciados via arquivos `.env` que estão devidamente configurados no `.gitignore` para evitar vazamentos de credenciais.
