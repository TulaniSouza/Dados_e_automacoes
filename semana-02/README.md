# Semana 02 - Estudos de Python e Automação

Este diretório contém uma série de scripts em Python desenvolvidos durante a segunda semana de aprendizado. O foco destes exercícios foi praticar estruturas de repetição, condicionais, manipulação de strings, listas, dicionários e bibliotecas padrão.

## Scripts Incluídos

### 1. [Gerador de Senhas](gerador_senhas.py)
Um utilitário que gera senhas seguras e aleatórias. O usuário define o comprimento da senha, e o script utiliza letras, números e caracteres especiais.

### 2. [Lista de Compras Inteligente](lista_compras.py)
Permite ao usuário criar uma lista de compras de forma interativa. Os itens são adicionados um a um até que o comando 'sair' seja digitado, exibindo ao final uma lista numerada.

### 3. [Organizador de Nomes](organizador.py)
Este script coleta nomes, trata a formatação (Capitalize) e os organiza em ordem alfabética. Ideal para praticar o método `.sort()` e limpeza de strings com `.strip()`.

### 4. Quiz de Cibersegurança
Um jogo interativo de perguntas e respostas focado em boas práticas de segurança digital. O script calcula a pontuação final e classifica o nível de conhecimento do usuário.

### 5. Saudação Personalizada (Olá)
Um script de interação inicial que coleta dados do usuário (nome, idade, altura) e verifica se ele é um estudante de cibersegurança da comunidade Kensei.

### 6. Exemplos de Listas e Dicionários
Arquivo de apoio contendo exemplos práticos de como declarar e acessar elementos em listas e dicionários no Python.

## Como Executar

Certifique-se de ter o Python instalado em sua máquina. Para rodar qualquer um dos scripts, utilize o terminal:

```bash
python nome_do_arquivo.py
```
